# The_Hungry_Table

 🍽️*Restro-*                                      
​A modern, clean, and responsive landing page for a restaurant named Restro, built using HTML and CSS. This project serves as a showcase for restaurant branding, menu presentation, and table booking interfaces.

​📌 PROJECT OVERVIEW-

​Restro is a visually appealing front-end project designed to offer users an intuitive browsing experience for a restaurant. It features a dark-themed UI with attractive typography, high-quality images, and clearly structured sections to present food items, services, and reservation options.

✨ FEATURE-                          
​Hero Section: Eye-catching headline with dynamic call-to-action (CTA) buttons ("Book Table").
​Navigation Menu: Easy access to Home, About, Food, Bookings, Services, and Contact sections.
​Responsive Layout: Clean design structured with modern CSS.
​Rich Visuals: High-resolution imagery to highlight culinary offerings.
